# agtoosa-next

Use when the user asks for `/agtoosa-next`, `$agtoosa-next`, or wants to advance the AgToosa lifecycle with one command.

## Execute

1. Read `Docs/AgToosa_Next.md` and follow the routing algorithm.
2. **Mandatory:** run `bash agtoosa.sh --status-line [path] --route-hint --format json` before dispatch.
3. Apply build approval override when spec lacks `## ✅ Spec Approved`.
4. Dispatch exactly **one** lifecycle workflow (`spec`, `build`, `review`, or `ship`).
5. Honor Phase Stop inside the dispatched workflow.
6. **Distinct from `/agtoosa-help next`:** this skill **executes** workflows; help next is read-only.
7. On successful completion, print the dual-line phase close from the dispatched workflow plus: *Say `/agtoosa-next` again when ready to advance.*

## Sub-commands

- `dry` — preview dispatch only
- `pick` — idle cold-start with user backlog selection
